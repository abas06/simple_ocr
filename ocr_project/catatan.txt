  CATATAN SERVER - simple_ocr
  VPS: 157.20.105.143 | Django + Gunicorn + Nginx

[ GUNICORN - Aplikasi Django ]
 
  Matikan aplikasi:
    systemctl stop gunicorn
 
  Hidupkan aplikasi:
    systemctl start gunicorn
 
  Restart aplikasi:
    systemctl restart gunicorn
 
  Cek status:
    systemctl status gunicorn
 
 
[ NGINX - Web Server ]
 
  Matikan Nginx:
    systemctl stop nginx
 
  Hidupkan Nginx:
    systemctl start nginx
 
  Restart Nginx:
    systemctl restart nginx
 
  Reload config (tanpa downtime):
    systemctl reload nginx
 
  Cek status:
    systemctl status nginx
 
 
[ ALUR UPDATE CODE DARI GITHUB ]
 
  1. cd /var/www/simple_ocr/ocr_project
  2. git pull
  3. systemctl restart gunicorn
 
 
[ CEK LOG ERROR ]
 
  Log Gunicorn:
    journalctl -u gunicorn -n 50
 
  Log error Nginx (live):
    tail -f /var/log/nginx/error.log
 
  Log akses Nginx (live):
    tail -f /var/log/nginx/access.log
 
  Cek syntax config Nginx:
    nginx -t
 
 
[ CATATAN PENTING ]
 
  - Setelah git pull, WAJIB restart gunicorn
  - Jika tidak bisa diakses, cek status gunicorn DAN nginx
  - Keduanya harus: active (running)
